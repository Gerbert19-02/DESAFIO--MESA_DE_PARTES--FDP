\# Mesa de Partes Digital



Prototipo en Python de una mesa de partes digital para registrar, validar, buscar y ordenar expedientes. Guarda los datos en un archivo de texto para no perder ningún trámite.



Curso: Fundamentos de Programación (CIIN1205P), UPN. Grupo 5.



\## Archivos



\- `main.py`: menú principal y operaciones (registrar, buscar, ordenar).

\- `validaciones.py`: validación de DNI (8 dígitos), RUC (11 dígitos) y folios (mayor a 0).

\- `archivos.py`: guardado y carga de expedientes en `expedientes.txt`.



\## Cómo ejecutarlo



1\. Instalar Python 3.

2\. Abrir una terminal en la carpeta del proyecto.

3\. Ejecutar: `python main.py`



\## Opciones del menú



1\. Registrar expediente

2\. Buscar expediente por código

3\. Ordenar expedientes por código

4\. Salir
